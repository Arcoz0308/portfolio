# Arcoz

Portfolio en français réalisé avec React, TypeScript, Vite et Tailwind CSS. Le mode Discord présente les projets dans un serveur de démonstration avec `@arcscord/discord-ui`.

## Lancer en local

```sh
pnpm install --frozen-lockfile
pnpm dev
```

`pnpm build` génère le site statique dans `dist/`.
